# نظام إدارة الفواتير

نظام متكامل لإدارة الفواتير والعملاء باللغة العربية.

## المميزات
- إدارة الفواتير
- حسابات العملاء
- تقارير المبيعات
- حاسبة التكاليف

## متطلبات التشغيل
- PHP 7.4+
- MySQL 5.7+
- XAMPP أو أي خادم ويب محلي

## طريقة التثبيت
1. قم بتنزيل أو استنساخ المشروع
2. ضعه في مجلد htdocs ضمن XAMPP
3. قم بإنشاء قاعدة بيانات باسم invoicing_system
4. استورد ملف قاعدة البيانات من مجلد database
5. قم بتشغيل المشروع من خلال localhost/invoicing_system
